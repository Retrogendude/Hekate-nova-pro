# Hekate Nova Pro
**Languages:** [Français](README.md) · [English](README.en.md) · [Español](README.es.md) · **Русский**

Экспериментальная кастомизация Hekate / Nyx: интерфейс Nova, аппаратная диагностика, кастомизация и поддержка дока и беспроводных Joy-Con. Неофициальный проект; авторы исходных компонентов сохраняют свои права и их указание.

## Загрузка

**[Бета v32: файлы и исходники](https://github.com/Retrogendude/Hekate-nova-pro/releases/tag/v32)** · [Все версии](https://github.com/Retrogendude/Hekate-nova-pro/releases) · [Полная история изменений](CHANGELOG.md) · [Руководство по использованию](docs/NOTICE-UTILISATION.md)

В v32 улучшены экспертный раздел памяти и восстановление ставшего беззвучным Joy-Con. Тесты на ПК и компиляция проверены; **радиус действия 2–3 метра ещё предстоит проверить на консоли**. Ранние версии сохранены для истории и не являются рекомендуемыми обновлениями.

## Возможности

- Главный экран Nova в виде плиток или карусели, настройки разнесены по вкладкам, окна подогнаны под баннеры.
- Семь языков: английский, французский, испанский, итальянский, русский, немецкий, португальский; шрифты с SD и регулируемый размер текста.
- Независимые цвета, палитра с предпросмотром, обои, прозрачность, значки PNG и отключаемый блик выбора.
- Встроенная диагностика из HWTest-RCM: 42 записи, экспортируемые отчёты, сводка по компонентам, интерактивные проверки и отдельный тест ОЗУ с возвратом в Hekate.
- Упрощённое / экспертное разбиение памяти, отображение размеров в ГБ, резервы и подтверждения Hekate сохранены.
- Вывод на ТВ через док на совместимых консолях: только ТВ или ТВ + экран консоли. У Switch Lite нет вывода на ТВ.
- Joy-Con по Bluetooth: чтение сопряжений, приватная резервная копия на SD, автоматическая загрузка без Joy-Con на направляющих и фоновая обработка. Подключение и дальность остаются экспериментальными.

## Установка

**[Открыть полное руководство](docs/NOTICE-UTILISATION.md)**: установка, первые настройки, обои, шрифты, значки, диагностика, док и беспроводные Joy-Con.

Загрузите скомпилированный пакет выбранной версии из Releases. При выключенной консоли сохраните копию bootloader, затем объедините поставляемые папки с корнем SD, заменяя только поставляемые файлы. Сохраняйте личные конфигурации и сопряжения. Используйте payload, соответствующий версии, либо поставляемый bootloader/update.bin — в зависимости от способа загрузки.

Инструкции, специфичные для каждой версии, её ограничения и её проверки приведены в docs/releases и в её архиве. Версии v1–v5 сохранены только в виде исходников среди файлов, доступных здесь.

## Исходники и сборка

Папка hekate содержит исходники Hekate / Nyx выбранного снимка. Архивы оригинальных исходников остаются приложены к каждому релизу вместе со связанными скриптами сборки и проверки. Они сохраняют свою историческую структуру и служат эталоном для воспроизведения старой поставки.

В репозитории: перейдите в hekate, затем используйте Makefile проекта. Требуемые инструменты включают devkitARM, devkitA64, GNU Make, Python 3 и нативный компилятор C для компонентов, которым он нужен. Компаньон HWTest-RCM-0.15 и дополнительные инструменты сохранены там, где они присутствовали в архиве. Об особенностях Windows см. BUILDING.txt и руководство соответствующей версии.

Локальные рабочие каталоги, SDK и данные консоли не импортированы. Скомпилированные архивы — это asset-ы Releases, а не ZIP-файлы, добавляемые при каждом коммите Git.

## История и состояние тестов

Сохранено 34 снимка: v1–v32 и два автономных ТВ-эксперимента. Теги и коммиты были восстановлены по архивам при их публикации; они не претендуют на воспроизведение исходных дат или коммитов разработки. Была найдена резервная копия исходников v15 и сопоставлена с хешами изменённых исходников, сохранённых в доказательствах этой версии; два сгенерированных файла payload в этот архив исходников не входят.

Встроенные предпросмотры, тесты с эмулированными периферийными устройствами и отзывы с консоли различаются в руководствах. Вердикт PASS охватывает только реально выполненные проверки. Результаты по ОЗУ, сенсорному экрану и экрану имеют собственные ограничения, подробно описанные в документации.

## Отчёты по Bluetooth

Чтобы сообщить о проблеме, после теста остановите службу Bluetooth и сохраните bootloader/bluetooth/last-session.txt. Укажите версию, модель, расстояние и используете ли вы док. **Не публикуйте файлы joycon-pairing.bin / .bak, prod.keys, title.keys или личные дампы.**
