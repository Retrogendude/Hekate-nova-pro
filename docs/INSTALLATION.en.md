# Using the archives
**Languages:** [Français](INSTALLATION.md) · **English** · [Español](INSTALLATION.es.md) · [Русский](INSTALLATION.ru.md)

**[See the full user guide](NOTICE-UTILISATION.md)** for the installation steps and the settings for wallpapers, fonts, icons and Nova features.

The releases contain the original ZIPs and their SHA-256. The source archives and the installable packages are distinct. The early prototypes do not have a preserved installable package.

For the current version, see the v32 guide. Keep personal settings and files; merge the supplied folders. The payload and Nyx must come from a consistent set. An update does not require formatting the SD card.

Partitioning changes the medium only after the confirmations provided by Hekate. Updating the interface does not launch these operations. The tests published on PC do not perform partitioning on a real card.
