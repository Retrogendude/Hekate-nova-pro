# Utiliser les archives

Les releases contiennent les ZIP d’origine et leurs SHA-256. Les archives de sources et les paquets installables sont distincts. Les premiers prototypes ne disposent pas d’un paquet installable conservé.

Pour la version courante, consulter la notice v32. Conserver les réglages et fichiers personnels ; fusionner les dossiers fournis. Le payload et Nyx doivent provenir d’un ensemble cohérent. Une mise à jour ne nécessite pas un formatage de la carte SD.

Le partitionnement modifie le support uniquement après les confirmations prévues par Hekate. La mise à jour de l’interface ne lance pas ces opérations. Les tests publiés sur PC n’exécutent pas de partitionnement sur une carte réelle.
