# Использование архивов
**Languages:** [Français](INSTALLATION.md) · [English](INSTALLATION.en.md) · [Español](INSTALLATION.es.md) · **Русский**

**[Открыть полное руководство по использованию](NOTICE-UTILISATION.md)** — шаги установки и настройки обоев, шрифтов, значков и функций Nova.

Релизы содержат оригинальные ZIP-файлы и их SHA-256. Архивы исходников и устанавливаемые пакеты — это разные вещи. У ранних прототипов сохранившегося устанавливаемого пакета нет.

Для текущей версии см. руководство v32. Сохраняйте личные настройки и файлы; объединяйте поставляемые папки. Payload и Nyx должны происходить из согласованного набора. Обновление не требует форматирования SD-карты.

Разбиение памяти изменяет носитель только после подтверждений, предусмотренных Hekate. Обновление интерфейса не запускает эти операции. Опубликованные тесты на ПК не выполняют разбиение памяти на реальной карте.
