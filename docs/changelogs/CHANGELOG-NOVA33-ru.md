# Hekate Nova Pro v33 — тестовая бета-версия

- Упрощённый китайский добавлен как восьмой язык в настройках и при первом запуске.
- Только для китайского используется обязательный специальный шрифт. Личный шрифт сохраняется для других языков, размер текста можно менять.
- Lecture.nyxf автоматически используется для языков на латинице; для русского по умолчанию выбран встроенный шрифт. Исходный шрифт Hekate доступен в списке.
- В комплекте три статичных фона, пять значков Nova и предоставленное изображение Launcher для главной плитки.
- Настройки новой установки: французский язык, Carbon Cyan, непрозрачность окон и значков 75%, текст 30 пикселей, заданные цвета и светлый загрузочный логотип. Сохранена исходная настройка часов.
- Заметный доступ к Auto Boot, задержке, Auto NoGC и Auto HOS Power Off. Яркость открывает существующий регулятор без дублирования.
- Постраничный выбор Auto Boot в стиле Nova без вертикального списка с сохранением индексов конфигураций Hekate.
- Отдельный тест памяти получил китайский интерфейс и символы 16 × 16; сохранена совместимость с семью прежними языковыми пакетами.
- При отсутствии или повреждении китайского шрифта временно используется английский. Личный шрифт и ранее сохранённые настройки не перезаписываются.

Бета-версия для проверки на консоли. Тесты на ПК не заменяют испытания оборудования. Проверены основные надписи, отдельные предупреждения и китайский интерфейс теста памяти; длинные отчёты содержат машинный перевод и требуют языковой проверки. Публикация на GitHub ожидает результатов испытания.
