# Hekate Nova Pro v33.1 beta

- Плитка запуска: маленький значок /icone/launch.png независим от большого фона /icone/Launcher.png; фон меняется в Nova с соответствующим предпросмотром.
- Авторы: HWTest-RCM 0.15 — Creased (Baptiste MOINE), в разделе свободного ПО.
- Внешний вид и параметры: убраны фоны строк проверки резервных копий и эффектов выбора; рамка системных параметров приведена к общему стилю.
- Резервное копирование и восстановление emuMMC: активная рамка на внешней панели без смещённого двойного контура; логика кнопок сохранена.
- Отдельные стандартный и экспериментальный пакеты 8 ГБ для физически модифицированных консолей Erista V1 и Mariko V2/Lite/OLED. Используется официальный программный флаг Hekate без записи предохранителей.
- Диагностика ОЗУ сохраняет режим 8 ГБ при запуске и возврате, выбирает профиль по платформе и объёму и прекращает тест при изменении объёма после тренировки.
- 64-битные вычисления верхних адресов и отчёт о реальном объёме: проверяется 8176 МиБ из 8192 МиБ, 16 МиБ защищены для рабочих данных.
- Для режимов свыше 4 ГБ требуется Atmosphère 1.11.0 или новее: memmode=1 в записи Hekate fss0 либо enable_mem_mode=1 в exosphere.ini для fusee. Существующие конфигурации автоматически не меняются.

Бета: сборки ARM и проверки на ПК пройдены. Режим 8 ГБ, особенно адаптированный профиль Erista, требует проверки на каждой платформе; совместимость со всеми заменяемыми чипами не подтверждена. Длинные китайские отчёты требуют языковой проверки.

## v33

- Упрощённый китайский добавлен как восьмой язык в настройках и при первом запуске.
- Только для китайского используется обязательный специальный шрифт. Личный шрифт сохраняется для других языков, размер текста можно менять.
- Lecture.nyxf автоматически используется для языков на латинице; для русского по умолчанию выбран встроенный шрифт. Исходный шрифт Hekate доступен в списке.
- В комплекте три статичных фона, пять значков Nova и предоставленное изображение Launcher для главной плитки.
- Настройки новой установки: французский язык, Carbon Cyan, непрозрачность окон и значков 75%, текст 30 пикселей, заданные цвета и светлый загрузочный логотип. Сохранена исходная настройка часов.
- Заметный доступ к Auto Boot, задержке, Auto NoGC и Auto HOS Power Off. Яркость открывает существующий регулятор без дублирования.
- Постраничный выбор Auto Boot в стиле Nova без вертикального списка с сохранением индексов конфигураций Hekate.
- Отдельный тест памяти получил китайский интерфейс и символы 16 × 16; сохранена совместимость с семью прежними языковыми пакетами.
- При отсутствии или повреждении китайского шрифта временно используется английский. Личный шрифт и ранее сохранённые настройки не перезаписываются.
