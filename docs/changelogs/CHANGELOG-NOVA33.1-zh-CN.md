# Hekate Nova Pro v33.1 beta

- 启动磁贴：左上角的小图标 /icone/launch.png 与大背景 /icone/Launcher.png 独立，背景可在 Nova 中更换，预览与实际一致。
- 鸣谢：在自由软件页面列出 HWTest-RCM 0.15 及其开发者 Creased（Baptiste MOINE）。
- 外观与选项：移除备份验证及选择效果行的底色，统一系统选项面板的边框。
- emuMMC 备份与恢复：活动边框位于外层面板，消除错位双框，保留按钮行为。
- 分别提供标准包与实验性 8GB 包，后者仅用于已物理扩容的 Erista V1 和 Mariko V2/Lite/OLED。使用 Hekate 官方软件标志，不写入熔丝。
- 内存检测：启动和返回时保留 8GB 模式，按平台和容量选择训练配置；训练后容量不一致则停止检测。
- 采用 64 位计算访问高位地址，并报告实际容量：8192 MiB 中可测试 8176 MiB，另外 16 MiB 用于受保护的工作数据。
- 超过 4GB 的内存模式需要 Atmosphère 1.11.0 或更新版本：Hekate fss0 启动项使用 memmode=1，fusee 则在 exosphere.ini 中使用 enable_mem_mode=1。不会自动修改现有配置。

测试版：ARM 编译与电脑端检查已通过。8GB 模式，尤其是调整后的 Erista 配置，仍需在各平台实机验证；不保证所有替换内存芯片均兼容。较长的中文报告仍含待校对的机器翻译。

## v33

- 新增简体中文，现支持八种语言，可在设置和首次启动时选择。
- 中文模式使用专用字体，并禁用自定义字体选择。其他语言的个人字体设置会保留，文字大小仍可调整。
- 拉丁字母语言默认使用 Lecture.nyxf；俄语默认使用内置字体。字体列表中也可选择 Hekate 原版字体。
- 内含三张静态壁纸、五个 Nova 图标，以及用户提供的主磁贴 Launcher 图像。
- 全新安装的默认设置：法语、Carbon Cyan 壁纸、窗口与图标不透明度 75%、30 像素文字、指定配色及浅色启动标志。首次启动仍需在主机上设置日期和时间。
- 启动选项入口更加明确，包含自动启动、启动延时、Auto NoGC 和 HOS 自动关机。亮度入口打开原有调节器，不重复创建。
- 自动启动配置改为 Nova 风格分页选择，取消纵向列表，保留 Hekate 原有的主配置与附加配置索引。
- 独立内存测试新增中文界面和 16 × 16 字符，并兼容原有七种语言的数据包。
- 中文字体文件缺失或无效时，本次会话使用英语，保留个人字体设置。安装包不会覆盖已有配置文件。
