# Hekate Nova Pro v33.2 beta

- Leuchtende Auswahlrahmen für alle Startkacheln, drei emuMMC-Verwaltungsaktionen, vier Sicherungsaktionen, drei Wiederherstellungsaktionen und acht USB-Werkzeuge.
- Rahmen folgen dem Joy-Con-Zeiger oder der Touch-Auswahl; Tastenaktionen bleiben erhalten, deaktivierte Kacheln verlieren den Rahmen.
- Vollständiger Außenrahmen für aktivierte rohe SD-emuMMC-Partition und Schreibschutz, einschließlich der zuvor unvollständigen Unterkante. Statusrahmen bleiben ohne Animation sichtbar.

PC: 192 selection/outline cases + 683 regression scenes; ARM build and binary metadata verified. Console test pending. RAM 8GB remains experimental, as in v33.1.
