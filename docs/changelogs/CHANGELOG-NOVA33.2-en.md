# Hekate Nova Pro v33.2 beta

- Glowing selection outlines on all home tiles, three emuMMC management actions, four Backup actions, three Restore actions and eight USB Tools actions.
- Outlines follow the Joy-Con pointer or touch selection; button actions are preserved and disabled cards lose their outline.
- Complete outer outlines for enabled raw SD emuMMC and Read-only options, including the previously incomplete bottom edge. State outlines remain visible without animations.

PC: 192 selection/outline cases + 683 regression scenes; ARM build and binary metadata verified. Console test pending. RAM 8GB remains experimental, as in v33.1.
