# Hekate Nova Pro v33.2 beta

- Светящиеся рамки всех плиток главного экрана, трёх действий управления emuMMC, четырёх действий копирования, трёх восстановления и восьми инструментов USB.
- Рамка следует за указателем Joy-Con или сенсорным выбором; действия кнопок сохранены, рамка отключённых плиток убирается.
- Полный внешний контур активных параметров раздела SD emuMMC и Только чтение, включая ранее неполный нижний край. Контуры состояния видны без анимации.

PC: 192 selection/outline cases + 683 regression scenes; ARM build and binary metadata verified. Console test pending. RAM 8GB remains experimental, as in v33.1.
