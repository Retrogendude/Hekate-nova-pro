# Hekate Nova Pro v33.3 beta

- Выбор цвета фона заменён на Ореол в разделе Интерфейс > Темы и цвета > Цвета.
- Цвет 1 и Цвет 2 независимо задают градиент рамки выбора с предпросмотром до сохранения.
- Оба цвета сохраняются при смене вкладок и записываются в nyx.ini. По умолчанию синий/фиолетовый; существующий фон сохранён.

PC: 98 configuration checks + 24 Halo scenes + 192 selection/outline cases + 683 regression scenes; ARM build and binary metadata verified. Console test pending. RAM 8GB remains experimental, as in v33.2.


# Hekate Nova Pro v33.2 beta
