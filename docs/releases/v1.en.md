# Hekate 6.5.4 — Diagnostic tab, prototype 1

This working version adds a Diagnostic tab to Nyx. The tests run directly in Nyx, without launching HWTest-RCM separately.

Integrated from HWTest-RCM 0.15: screen identification, LCD/OLED backlight status, DRAM identification and channel comparison. Textual PASS/WARN/FAIL results. The probe sources are kept in frontend/diagnostics, with a dedicated Nyx adapter.

Not integrated: power, storage, audio, Wi-Fi/Bluetooth, input diagnostics, full RAM test, report export. The DRAM test present identifies the memory; it does not check all of its cells.

The tab is added after Options in order to preserve the indices of the existing tabs. No test runs when the tab is opened.

Build: use the Hekate procedure with devkitARM, then build Nyx via its Makefile (from nyx: make). No compiled binary is provided. The ARM build tools are not available in the environment used; neither the build, nor the display on console, nor the hardware measurements have been validated. This prototype is intended for review and a build before any installation.

Points to check on hardware: width of the six tabs, opening/closing of results, repeated runs, LCD/OLED diagnostics, Erista/Mariko DRAM identification. The verdicts are observations of the registers and do not constitute a complete validation of the hardware.

Provenance: user archives hekate-6.5.4.zip and HWTest-RCM-0.15.zip. Hekate licence kept in LICENSE. The provenance comments of the HWTest-RCM probes are kept. The HWTest-RCM archive provided does not contain an identified root licence; check the redistribution rights of its probes before public distribution.
