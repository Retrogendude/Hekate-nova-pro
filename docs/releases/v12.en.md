## Full historical notice

The instructions and paths below relate to this version's archive. They do not automatically describe the latest version. The limitations and validations remain those stated at the time.

HEKATE NOVA PRO - CUSTOMISED VERSION 12
Hekate 6.5.4 / Nyx 1.9.4

INSTALLATION
1. Keep a copy of the bootloader folder and of the current settings.
2. Merge bootloader, fonts and wallpapers with the root of the SD card.
3. Use hekate_nova_pro_6.5.4_v12.bin with the usual method.
   bootloader/update.bin contains exactly this same payload.
No nyx.ini or hekate_ipl.ini is included: the settings remain in place.
The Hekate startup keeps the Nova Pro presentation already added in v11.

FIXES
- Wallpaper placed behind the menus and the windows.
- Six colours: background, texts, outlines, logo, icons and selection.
- Discrete WHITE diagonal reflection on the selected symbol. No animated outline.
- Logo opening the credits directly.
- Green/yellow/orange/red temperature according to the ranges indicated in the documentation.
- Active/Inactive switches matched to the theme.
- FIRST STARTUP: ORIGINAL time setting kept, with simply
  the seven languages added. Save and reload applies time and language.
  No second wizard, no reset of the existing time.

The new colours are found in Nyx Settings > Themes and colours.
The colour choices are applied after Save and reload.
The reflection remains white whatever the palette chosen.
The fixed BMP wallpapers are placed in wallpapers at the root of the SD.
The NYXF fonts are placed in fonts. The converters are provided.

The Nyx backups keep a recovery copy during the replacement.
If a backup fails, check the card and try again. Do not delete a
nyx.ini.nova.bak copy if the main nyx.ini file is absent.

Compilation and trials of the real code on PC carried out. Version to be tested on Switch:
no hardware trial or FPS measurement on console has been carried out here.
See documentation/CORRECTIONS-NOVA-PRO-V12.md and verification/.
