HEKATE NOVA PRO - PATCH 13
Hekate 6.5.4 / Nyx 1.9.4

- Fix for the internal order of the windows with an active wallpaper.
  The buttons and submenus find their normal path again on touch.
- Discrete white diagonal reflection on the WHOLE selected tile.
  The outlines remain fixed. No background effect.

INSTALLATION
1. Back up the current files and settings of the SD card.
2. Merge the provided bootloader folder with the one of the SD.
   Check the replacement of bootloader/sys/nyx.bin: this is the patch.
3. Use hekate_nova_pro_6.5.4_v13.bin with the usual method.
   bootloader/update.bin contains exactly this same payload.
The fonts and wallpapers folders can be merged for the resources.
No nyx.ini or hekate_ipl.ini is provided. The settings are kept.
The original time setting with the language choice remains unchanged.

TEST ON THE CONSOLE
Keep the background active, open the Nyx settings then Themes and colours.
Close, open Appearance, then return to the Tools, Info and Diagnostic tabs.
The reflection must cross the surface of the selected tile, without turning
around its border. Selection effects allows it to be disabled.

Compilation and trials of the real code on PC carried out. This version remains to be
validated on Switch: no hardware trial or console FPS measurement done here.
See documentation/CORRECTIONS-NOVA-PRO-V13.md and verification/.
