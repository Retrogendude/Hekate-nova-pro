INSTALLATION
1. Sauvegarder les fichiers et reglages actuels de la carte SD.
2. Fusionner le dossier bootloader fourni avec celui de la carte.
3. Utiliser hekate_nova_pro_6.5.4_v15.bin avec la methode habituelle.
   bootloader/update.bin contient exactement ce meme payload.
Remplacer Nyx ET le payload pour obtenir toutes les modifications du chargement.
Aucun nyx.ini ou hekate_ipl.ini n'est fourni. Les reglages sont conserves.
Le premier reglage d'heure d'origine avec choix de langue est conserve.
Effets de selection permet toujours de desactiver le reflet.
