## Full historical notice

The instructions and paths below relate to this version's archive. They do not automatically describe the latest version. The limitations and validations remain those stated at the time.

HEKATE NOVA PRO 16
Base: Hekate 6.5.4 / Nyx 1.9.4

INSTALLATION / UPDATE
Copy the contents of the package onto the SD card, keeping the folders
bootloader, fonts and wallpapers at the root.
Use hekate_nova_pro_6.5.4_v16.bin as payload.
The package contains no nyx.ini or hekate_ipl.ini: the existing preferences
and boot configurations are kept.

FIRST INSTALLATION
Background: wallpapers/Nova-Carbon.bmp.
Nova colours: dark background, light texts, turquoise accents.
Windows: 75% transparency, i.e. 25% opacity.
Icons: opacity 100%, adjustable independently.
Original date/time setting and language choice kept.
On an existing installation, the already saved theme and background remain
priority. The Reset button of the Themes and colours menu makes it possible to
return to the new Carbon/Nova choices, then to save them.

MAIN CHANGES
- Compact partition manager with simplified and expert modes.
- Checked console model and full emuMMC 29 GB / 58 GB rounded.
- Independent Linux and Android: 0, 16 or 32 GB each in simplified mode.
- Exact summary in MiB and invalid layouts blocked.
- Aligned backup/restore columns.
- USB tools and archive bit re-laid out.
- Package 1/2 logs in two tabs with internal scrolling.
- Active tab of the settings more visible.
- Brightness in Nyx Settings / System, to the right of the clock.
- Credits and Nova version updated.
- Animated blue/purple border on the selection and accelerated white reflection.
The reflection crosses the tile in 240 ms; full cycle of 720 ms.
The selection effects setting allows these effects to be turned off.
The waves/particles background animations remain removed.

PARTITIONING
The simplified values are space reservations. Then create
the emuMMC with its tool and install Linux/Android with the dedicated tools.
The complete Hekate allocations are kept: 29856 or 59680 MiB,
technical reservations included. Android 16/32 GB includes its system space.
The confirmations and the original automatic backup limit remain
in place. The expert mode keeps the manual options.

VERIFICATIONS
Compilation and tests on PC: see documentation/VERIFICATION-V16.json
and documentation/SUIVI-CAHIER-CHARGES-V16.md.
The 42 HWTest checks and the isolated memory service are kept.
Validation on console not carried out; the rendering measurements on PC are
not an FPS measurement on Switch.
