## Full historical notice

The instructions and paths below relate to this version's archive. They do not automatically describe the latest version. The limitations and validations remain those stated at the time.

HEKATE NOVA PRO 18 - Base Hekate 6.5.4 / Nyx 1.9.4

UPDATE
Copy the bootloader, fonts, wallpapers and icone folders to the root of
the SD card. Use hekate_nova_pro_6.5.4_v18.bin as payload.
The existing nyx.ini and hekate_ipl.ini files are kept.

CHANGES OF THIS VERSION
- Credits: only the four top tabs. No more lower pagination;
  licences and authors kept in two columns.
- Tile icons: PNG with transparency in /icone/. See the file
  /icone/LIRE-MOI.txt for the five file names and the dimensions.
  The Nova icons remain used if an image is missing or invalid.
- Image of the large Launch tile: choice of the PNGs of /icone/ in Nyx Settings
  > Themes and colours > Launch tile. Old BMPs still available.
- System options column: outlines removed from this column and from its
  options; the switches and their states remain visible.
- SD partitions: choice Switch V1 V2, Switch Lite, Switch OLED. The remaining
  FAT32 space is displayed for each calculable proposal, even if
  it does not match the console; this incompatibility continues
  to block the validation. V1 and V2 share the same profile.
- Linux/Android: Minimum below 16 GB, Recommended below 32 GB.
- Expert mode: emuMMC, Linux and Android sizes in GB. Capacity in both
  modes in MiB with the GB equivalent in brackets (base 1024).

All the functions and diagnostics of v17 are kept. The package
contains the seven languages; the existing preferences remain priority.

TV OUTPUT ON OFFICIAL DOCK
TV output is not yet activated. The study of the code and the development
steps are in documentation/DEVELOPPEMENT-TV-DOCK.md.
The video negotiation with the dock and the DisplayPort drivers have to be
developed and validated on hardware. The Switch Lite remains excluded.

VERIFICATIONS
Compilation and PC tests: documentation/VERIFICATION-V18.json.
The PNG decoder is tested on transparency, palettes, greyscale,
interlaced PNGs, resizing and invalid files. The partitioning tests use the real calculator
and the interface commands.
The original formatting and copying routines are kept.
Physical validation on Switch not carried out; the PC tests do not measure
the real FPS of the console.
