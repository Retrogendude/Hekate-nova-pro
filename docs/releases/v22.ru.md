# Hekate Nova Pro 22

Обновлённая функциональная основа: Hekate 6.5.5 / Nyx 1.9.5, со стилем Nova.
Эта версия исправляет ошибочное предупреждение Nyx и несколько возможных блокировок
беспроводных команд. Bluetooth-связь остаётся экспериментальной.

## Установка

1. Сохраните копию текущей папки bootloader.
2. Скопируйте предоставленную папку bootloader в корень SD-карты и согласитесь
   с заменой файлов. Удалять папку не нужно.
3. Запишите hekate_nova_pro_6.5.5_v22.bin или используйте предоставленный bootloader/update.bin.
4. Проверьте «22» в благодарностях и «Hekate 6.5.5 / Nyx 1.9.5».

Личные файлы nyx.ini и hekate_ipl.ini в этот пакет не
входят. Ваши настройки, темы, фоны, шрифты и конфигурации загрузки
сохраняются. Замены только payload без обновления nyx.bin недостаточно.

## Предупреждение «Old Nyx GUI found»

Поставленная v21 размещала метаданные Nyx в неверной позиции бинарного файла.
Это вызывало ложное предупреждение даже при наличии всех правильных файлов.
Теперь точка входа Nyx изолирована, и сборка отклоняется, если
размещение метаданных меняется. Проверка совместимости Hekate остаётся
активной: реальное смешение версий всё ещё может вызвать это предупреждение.

## Обновление Hekate / Nyx

Официальные изменения, касающиеся HOS 23.5.0, перенесены в ядро Nova,
включая исправление NOGC для FAT32, опубликованное после тега 6.5.5. Панели, значки,
цвета и компоновки Nova остаются от предыдущей версии.

Модуль emuMMC и компонент L4T sc7exit_b01.bin взяты из официального обновлённого
пакета 6.5.5, контрольная сумма которого проверена. Nyx и payload остаются
бинарными файлами Nova, собранными для этой версии, и не заменяются официальным
интерфейсом. Ресурсы Nova и диагностика сохранены.

Ссылки портирования:
- [Выпуск Hekate 6.5.5 / Nyx 1.9.5](https://github.com/CTCaer/hekate/releases/tag/v6.5.5)
- Код тега: 9593272c54f8dc127a5a25f91e1ac90e1be6205d.
- Финальное исправление FAT32: 8e1392df4569ac501a115867056b13c361429e9e.

## Беспроводные Joy-Con

В «Настройках Nyx → TV / Dock → Беспроводные Joy-Con»:

1. Прикрепите Joy-Con, уже сопряжённые с этой консолью, затем выберите «Прочитать сопряжения».
2. Проверьте импортированное количество, отсоедините Joy-Con и выберите «Включить Bluetooth».
3. Разбудите Joy-Con нажатием кнопки, оставьте стики в покое на мгновение,
   затем переместите стик и проверьте A / ZL / ZR.

Ключи остаются в памяти во время сессии. Они не записываются на SD,
и сопряжения, хранящиеся в Joy-Con, не изменяются. Служба остаётся
отключённой при каждом запуске. Она останавливается перед диагностикой, режимом USB и
запуском другой системы; перезапустите её вручную после диагностики.

Исправления навигации:
- Если выбранная сторона отсутствует, стик другого подключённого Joy-Con может управлять
  курсором. Сохранённая настройка предпочитаемой стороны сохраняется.
- A / ZL / ZR пробуждают скрытый курсор и остаются доступными во время центрирования.
- Простые отчёты 0x3F декодируются, помимо 0x21 и 0x30. Отслеживается подтверждение
  полного режима, а старые команды отпускаются.

Одни только счётчики HCI не доказывают получение кнопок. Дополнительная строка
состояния теперь позволяет различать:

| Поле | Чтение |
| --- | --- |
| Отчёты Joy-Con | Количество фактически декодированных отчётов, левый / правый |
| ID | Тип отчёта, обычно 30 в полном режиме, 3F в простом режиме |
| HID | 1, когда соединение с контроллером открыто |
| ACK | 1, когда подтверждён полный режим или получен отчёт 30 |
| ERR | Последний код ошибки открытия соединения, 00 при отсутствии записанной ошибки |
| BTN | Декодированные кнопки; значение должно меняться во время нажатия |
| XY | Значения стиков; около 2048,2048 в покое в полном режиме |

Если команды по-прежнему не отвечают, зафиксируйте эту строку, удерживая A,
затем перемещая стик. Это позволяет отделить проблему соединения, декодирования
и навигации. Ни один сбой прототипа сам по себе не является
диагнозом аппаратного отказа.

## Проверки и ограничения

Сборка ARM, позиции и версии заголовков, реальные пути
декодирования / объединения / указателя вплоть до нажатия LVGL, меню и регрессии ТВ
проверяются на ПК с подменёнными аппаратными входами. Две блокировки
навигации были воспроизведены на коде v21 перед проверкой исправлений.
Программа проверки также отклоняет точку входа Nyx, сдвигающую заголовок.

Физическая проверка этой v22 на вашей консоли по-прежнему необходима: ПК-тесты
не доказывают радиосоединение, запуск HOS или реальный HDMI-выход.
Настройки видеодрайвера и обнаружение дока остаются от Nova v20/v21.

## Лицензии

Эта версия сохраняет благодарности и лицензии компонентов. BTstack подчиняется
личной некоммерческой лицензии BlueKitchen, приложенной к пакету; поэтому не все
компоненты представляются как распространяемые под GPL. Проприетарная Bluetooth-прошивка
не предоставляется. См. также документы предыдущих версий.

Ссылка на простой формат Joy-Con: [драйвер SDL Switch](https://github.com/libsdl-org/SDL/blob/main/src/joystick/hidapi/SDL_hidapi_switch.c),
для левой/правой ориентаций при вертикальном использовании. Код SDL
в стек не включается; декодер Nova использует документированные форматы.
