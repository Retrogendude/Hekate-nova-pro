# Hekate Nova Pro25 — испытание переподключения Joy-Con

Сохранённая основа: Hekate6.5.5 / Nyx1.9.5. Интерфейс и настройки Nova сохранены.

Отчёт v24 подтверждает успешную аутентификацию для одного подключения, затем
потерю связи во время включения шифрования (08). Исправление
формата ключей из v24 сохранено. Проблема подключения остаётся.

Эта версия требует, чтобы консоль принимала основную роль, когда Joy-Con
инициирует переподключение, и запускает исходящие попытки последовательно.
Эти изменения проверены на ПК. Их эффективность на консоли ещё
нужно подтвердить: один только отчёт не позволяет с уверенностью отнести
обрыв к Bluetooth-роли.

## Установка и испытание

1. Скопировать содержимое ZIP в корень SD, заменив файлы
   папки **bootloader**. Файлы настроек не предоставляются.
2. При необходимости использовать **hekate_nova_pro_6.5.5_v25.bin**, затем перезапустить
   консоль полностью.
3. Открыть **Настройки → TV / Dock → Беспроводные Joy-Con**. Прикрепить Joy-Con,
   выбрать **Прочитать сопряжения**, затем отсоединить их и включить Bluetooth.
4. Нажать кнопку, чтобы разбудить их, и попробовать кнопки/стики.
5. Выбрать **Остановить Bluetooth** после испытания. Отчёт находится в
   `bootloader/bluetooth/last-session.txt`.

Не используйте в качестве критерия только состояние светодиодов: счётчики
отчётов и работа команд являются полезными индикаторами.
Ключи остаются в памяти, и их нужно перечитывать после каждого перезапуска.

## Новый отчёт

- AUTH=00 SEEN=1: событие подтверждает успешную аутентификацию.
- ENC=00 SEEN=1 ENABLED=1 or2: шифрование включено, пока связь активна.
- ENC=08 SEEN=1: связь истекла на этом этапе.
- DISC: причина отключения сохранена.
- ROLE=00: основная роль, известная стеку; 01: вторичная; FF: неизвестна.
  Полученные изменения роли появляются в trace13; политика,
  запрошенная при принятии, появляется в trace14.
- HOST=1: идентичность контроллера соответствует импортированным сопряжениям.
- SEEN=0: соответствующее событие не наблюдалось; 00 само по себе не доказывает успех.

Последние результаты остаются доступными после «Остановить», даже если нажать
её второй раз. Следующий запуск Bluetooth открывает новую сессию.
Отчёт включает версию контроллера, без адресов, ключей и необработанных пакетов.

Безопасность связи сохранена. Новое сопряжение не создаётся, и запись ключей
не выполняется. Предыдущие исправления Nyx, дока и диагностики
сохранены. Отдельная лицензия BTstack включена в документацию.
