# Hekate Nova Pro27 — Bluetooth profile adapted from HWTest-RCM

v27 takes the settings of the wireless controller service of HWTest-RCM:
base radio rate, standby management, transmission rate and extended serial
reading. The startup also uses its power and clock settings,
with restoration of the previous state on stop.

The Nova interface, the two Joy-Con, the imported keys, the security and the
previous connection fixes are kept. The Wi-Fi and Bluetooth diagnostics already
integrated remain in place. Base: Hekate6.5.5 / Nyx1.9.5.

Compilation and software tests successful. The operation on console remains
to be confirmed. The details of the adaptations appear in HWTEST-BLUETOOTH-SOURCES.md.

1. Copy the ZIP to the root of the SD, replacing the **bootloader** files.
2. Use **hekate_nova_pro_6.5.5_v27.bin** if necessary, then restart.
3. Attach the Joy-Con and choose **Read the pairings** in their wireless menu.
4. Detach them, enable Bluetooth, press a button and test the commands.
5. Choose **Stop Bluetooth** after the trial to record
   `bootloader/bluetooth/last-session.txt`.

The report adds BR_ONLY, the mode changes and reception
statistics. The grouped configurations are now all detailed,
without addresses, keys or raw data. After Stop, HID/ENABLED may be 0;
the report counters and the last results remain kept.

The user settings are not provided in the ZIP. The keys remain
in memory and have to be read again after the restart. The existing licences,
including that of BTstack, are included.
