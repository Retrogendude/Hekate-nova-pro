# Hekate Nova Pro 29 — сопряжения, сохранение на SD и переподключение

Форматирование SD-карты не является исправлением наблюдаемой проблемы.
Данные сопряжения считываются в Joy-Con. v28 получила оба
контроллера на одной OLED, тогда как R потерял соединение на другой.
Проход через Nintendo восстановил импорт 2/2; новое испытание затем
воспроизвело 0/2 на второй OLED. Точную причину на оборудовании ещё нужно выяснить.

Эта версия принимает два профиля хоста, уже проверенных читателем BDK:
Nintendo и стандартный. v28 требовала классификацию Nintendo даже для
стандартной записи, признанной действительной. Новый путь сохраняет
проверку контрольной суммы, активную запись, ненулевые ключи, стороны и
совместимость двух хостов. Усечённые ответы SPI больше не заполняют
кэш. Историческая экспортная функция Hekate сохраняет свою классификацию Nintendo.

Тайм-аут попытки подключения изменяется с 15,36 с до 5,12 с. Попытки
продолжаются, с интервалами, пока служба Bluetooth включена; они больше не
останавливаются на третьем сбое. Одновременно активна только одна
исходящая попытка. Восстановленное соединение сбрасывает счётчик восстановления в ноль.
Это улучшает восстановление после пробуждения или обрыва; пробуждение обычной кнопкой
и отсутствие обрывов на обеих консолях ещё нужно проверить.
Скорость радио, шифрование, управление каналами и ключи сохранены.

В меню «Беспроводные Joy-Con» появляются два новых действия:

- **Сохранить сопряжения**: после корректного чтения, при остановленном Bluetooth.
  Файл из 72 байт содержит необходимые данные обоих контроллеров
  в `bootloader/bluetooth/joycon-pairing.bin`. Это не полная копия
  памяти Joy-Con. Ключи сохраняются в открытом виде:
  храните этот файл приватно и не отправляйте его вместе с отчётами.
- **Загрузить сопряжения**: явно перезагружает этот файл в
  сессию после перезапуска. Ошибка формата или контрольной суммы приводит к его
  отклонению с сохранением ключей, уже находящихся в памяти.

Сохранение использует временный файл, затем сохраняет предыдущую версию
в `joycon-pairing.bak`. Загрузка пробует эту копию, если основной файл
отсутствует или повреждён. Файл `.bak` также содержит приватные ключи.
Сохранение с одним действительным контроллером остаётся сохранением 1/2.
«Стереть ключи» очищает сессию в памяти, а не файлы сохранения.
Файлы следует использовать со связанными контроллерами. Чтобы сравнить
две консоли, прочитайте и сохраните сопряжения, соответствующие каждому испытанию.
Если в системе Nintendo выполнено новое сопряжение, перечитайте затем
сохраните обновлённые данные перед повторным использованием сохранения на SD.

Установка и проверка:

1. Распаковать ZIP в корень SD, заменив `bootloader`, без форматирования.
   При необходимости использовать `hekate_nova_pro_6.5.5_v29.bin`, затем перезапустить.
2. С прикреплёнными Joy-Con прочитать сопряжения. Если 2/2, сохранить их до
   включения Bluetooth. Если 0/2 сохраняется, остановить и забрать отчёт.
3. Отсоединить контроллеры, включить Bluetooth и сначала попробовать обычную кнопку
   каждого контроллера для их пробуждения. Проверить перемещение и A/B.
4. Остановить Bluetooth и немедленно забрать `bootloader/bluetooth/last-session.txt`,
   не стирая ключи и не перечитывая сопряжения. Не прикладывать файлы
   сопряжения `.bin` или `.bak`.
5. Для проверки сохранности: перезапустить Nova, загрузить сопряжения с
   SD, затем повторить тест. Если сохранение действительно, для
   этой загрузки чтение с салазок не требуется.

Отчёт добавляет `recognized` (действительный профиль распознан) и `source` (1 салазки,
2 SD). При загрузке с SD классификация Nintendo не заполняется;
индикаторы салазок не означают новое физическое чтение.
Тип трассы 20 указывает запрошенный тайм-аут попытки в единицах Bluetooth.
Ни ключи, ни адреса, ни необработанные данные в отчёт не добавляются.

Сборка и проверки на ПК не заменяют аппаратную проверку.
Восстановление после тайм-аута проверяется на смоделированном радио; оно не
доказывает, что причина обрывов R исчезла. Ни стирание, ни
новое сопряжение в Joy-Con не отправляются. Основа: Hekate6.5.5 / Nyx1.9.5.
Пользовательские настройки в ZIP не включены. Лицензии сохранены.
