### DIAGNOSTIC-INTEGRATION.md

# Hekate 6.5.4 — Diagnostic tab, prototype 1

Update: this archive goes back to the original interface in prototype 3.
See `INTERFACE-ORIGINALE.md` for the interface changes and the validation
limits. The fix for reading the DRAM channels is retained:
the four expressions `(mrr & 0xFF00 >> 8)` now use
`((mrr & 0xFF00) >> 8)` to read the second byte rather than the first.

This working version adds a Diagnostic tab to Nyx. The tests run directly in Nyx, without launching HWTest-RCM separately.

Integrated from HWTest-RCM 0.15: screen identification, LCD/OLED backlight status, DRAM identification and channel comparison. Textual PASS/WARN/FAIL results. The probe sources are kept in frontend/diagnostics, with a dedicated Nyx adapter.

Not integrated: power, storage, audio, Wi-Fi/Bluetooth, input diagnostics, full RAM test, report export. The DRAM test present identifies the memory; it does not check all of its cells.

The tab is added after Options in order to preserve the indices of the existing tabs. No test runs when the tab is opened.

Build: use the Hekate procedure with devkitARM, then build Nyx via its Makefile (from nyx: make). No compiled binary is provided. The ARM build tools are not available in the environment used; neither the build, nor the display on console, nor the hardware measurements have been validated. This prototype is intended for review and a build before any installation.

Points to check on hardware: width of the six tabs, opening/closing of results, repeated runs, LCD/OLED diagnostics, Erista/Mariko DRAM identification. The verdicts are observations of the registers and do not constitute a complete validation of the hardware.

Provenance: user archives hekate-6.5.4.zip and HWTest-RCM-0.15.zip. Hekate licence kept in LICENSE. The provenance comments of the HWTest-RCM probes are kept. The HWTest-RCM archive provided does not contain an identified root licence; check the redistribution rights of its probes before public distribution.


### INTERFACE-ORIGINALE.md

# Hekate 6.5.4 — original interface, prototype 3

This variant returns to the original home screen of the user archive: four
Launch, More Configs, Payloads and emuMMC buttons, the Nyx settings at the bottom
left and the power buttons at the bottom right. The Home,
Tools, Console Info and Options titles are the original ones.

The new Diagnostic tab stays after Options. Its presentation follows
the Nyx theme: native buttons, descriptions on the right and thin separators.
It reuses the colours of the active theme and takes the custom background into account.
The available probes remain screen identification, backlight
status and DRAM identification; no test is started when the tab is opened.

Routing between Launch and More Configs still uses explicit
identifiers. These are the only two additions to the home screen construction
code of the original. The tab indices are preserved, Options = 4 and
Diagnostic = 5. The report details and the DRAM channel reading
fix from the previous variant are retained.

## Validation and limits

The home screen construction code was compared with the original archive:
it is identical after removal of the two identifier assignments.
The Diagnostic entry points, the tab indices and the syntax of the
interactive mockup were checked. The mockup is an interactive approximation
of the original theme, with substitute symbols; it is not
a capture taken on a console and it runs no hardware test.

No ARM build chain is available in the environment.
This deliverable contains the sources only, with no binary. The build and
the trials on console remain to be done, in particular the legibility of the six
tabs, the diagnostic buttons and the Erista/Mariko and LCD/OLED measurements.
The rendering of the mockup has not been checked in a browser.

See `DIAGNOSTIC-INTEGRATION.md` for the scope of the probes and their provenance.
