# Hekate 6.5.4 — вкладка Diagnostic, прототип 1

Обновление: этот архив предлагает два главных экрана в прототипе 4.
См. `INTERFACE-ACCUEIL.md` об изменениях интерфейса и ограничениях
проверки. Исправление чтения каналов DRAM сохранено:
четыре выражения `(mrr & 0xFF00 >> 8)` теперь используют
`((mrr & 0xFF00) >> 8)` для чтения второго байта, а не первого.

Эта рабочая версия добавляет вкладку Diagnostic в Nyx. Тесты выполняются непосредственно в Nyx, без отдельного запуска HWTest-RCM.

Интегрировано из HWTest-RCM 0.15: идентификация экрана, состояние подсветки LCD/OLED, идентификация DRAM и сравнение каналов. Текстовые результаты PASS/WARN/FAIL. Исходный код зондов сохранён в frontend/diagnostics, со специальным адаптером Nyx.

Не интегрировано: диагностика питания, хранилища, звука, Wi-Fi/Bluetooth, входов, полный тест RAM, экспорт отчёта. Присутствующий тест DRAM идентифицирует память; он не проверяет все её ячейки.

Вкладка добавляется после Options, чтобы сохранить индексы существующих вкладок. При открытии вкладки ни один тест не запускается.

Сборка: использовать процедуру Hekate с devkitARM, затем собрать Nyx через её Makefile (из nyx: make). Скомпилированный бинарный файл не предоставляется. Инструменты сборки ARM недоступны в использованной среде; ни сборка, ни отображение на консоли, ни аппаратные измерения не были проверены. Этот прототип предназначен для обзора и сборки перед любой установкой.

Что проверить на оборудовании: ширину шести вкладок, открытие/закрытие результатов, повторные запуски, диагностику LCD/OLED, идентификацию DRAM Erista/Mariko. Вердикты являются наблюдениями регистров и не представляют собой полную проверку оборудования.

Происхождение: пользовательские архивы hekate-6.5.4.zip и HWTest-RCM-0.15.zip. Лицензия Hekate сохранена в LICENSE. Комментарии о происхождении зондов HWTest-RCM сохранены. В предоставленном архиве HWTest-RCM не обнаружена идентифицированная корневая лицензия; проверьте права на распространение его зондов перед публичным выпуском.

# Hekate 6.5.4 — две компоновки главного экрана, прототип 4

Эта версия включает две компоновки главного экрана Nyx, выбираемые
в настройках. Функции Hekate и новая вкладка Diagnostic остаются
доступными в обоих режимах.

## Выбор компоновки

1. Открыть настройки Nyx с главного экрана.
2. Использовать кнопку «Disposition» в верхней части настроек Nyx.
3. Выбрать «Tuiles» или «Carrousel».
4. Использовать «Сохранить и перезагрузить», чтобы применить выбор.

Закрытие селектора без сохранения сохраняет предыдущую компоновку.
Выбор хранится в разделе `[config]` файла `bootloader/nyx.ini`:

```ini
home_layout=0
```

`0` выбирает плитки, а `1` — карусель. Отсутствующий или недопустимый параметр
использует плитки. Существующий параметр `homescreen` остаётся независимым:
чтобы отображать главный экран при запуске, выберите «Main menu» в «Home Screen».

## Два режима

**Плитки** (Tuiles): крупная команда запуска и четыре доступа к дополнительным
конфигурациям, payloads, управлению emuMMC и Diagnostic.

**Карусель** (Carrousel): карточки перемещаются в горизонтальной области. Стрелки
или видимая карточка меняют выбор; «Открыть» (Ouvrir) запускает только
выбранную функцию. Выбор никогда не запускает payload автоматически.
Режим не обещает прямой навигации крестовиной:
Joy-Con сохраняют поведение указателя, уже присутствующее в Nyx.

Оба режима используют встроенные формы и шрифты, без дополнительных
изображений для размещения на SD-карте. Французские метки в исходном коде
используют ASCII, совместимый со встроенными шрифтами.

## Сохранение и диагностика

Селектор проверяет наличие Nyx перед перезагрузкой. Ошибка
сохранения должна показать сообщение и предотвратить перезагрузку. Ошибки
записи и закрытия файла конфигурации теперь учитываются
модулем записи конфигурации Nyx.

Доступные проверки Diagnostic остаются прежними: идентификация экрана,
состояние подсветки и идентификация DRAM. Звук, радиоинтерфейсы,
хранилище и полный тест RAM не интегрированы. Исправление
чтения каналов DRAM из предыдущего прототипа сохранено.

## Проверка и ограничения

Эта поставка содержит только исходный код. Цепочка сборки
ARM не установлена в использованной среде; ни скомпилированный бинарный файл,
ни испытание на консоли не предоставляются. Интерактивный макет показывает выбор
в настройках и не читает и не записывает реальную SD-карту.

Перед установкой соберите Hekate и Nyx цепочкой, предусмотренной их
Makefile, затем проверьте обе компоновки на экране 1280 × 720,
быстрые ссылки, настройки, сохранение выбора после перезагрузки,
отмену, ошибки записи и навигацию касанием/Joy-Con.

См. `DIAGNOSTIC-INTEGRATION.md` о происхождении и объёме зондов.
