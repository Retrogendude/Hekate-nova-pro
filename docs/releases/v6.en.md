## Full historical notice

The instructions and paths below relate to this version's archive. They do not automatically describe the latest version. The limitations and validations remain those stated at the time.

HEKATE 6.5.4 / NYX 1.9.4 - TRANSPARENT INTERFACE AND LANGUAGES, PROTOTYPE 6

Complete build succeeded. This version remains experimental:
no trial on a real console has yet been carried out.

NEW FEATURES
- Modern rounded theme applied to the menus, submenus and controls.
- Transparent card backgrounds, icons, panels, buttons and selections.
  The overlaid windows and dialogs keep a legible dark base.
- Diagnostic icon added in the tab and on the home card.
- Language choice: English, French, Spanish, Italian, Russian, German,
  Portuguese. Unicode fonts for accents and Cyrillic.
- Two home screens: Tiles and Carousel, kept in the Nyx settings.
- The whole HWTest-RCM 0.15 table: 42 native entries, categories,
  individual execution, detailed results and export to the SD card.
- Separate RAM test: one sequence of the 7 advanced patterns on the
  accessible unreserved areas, then automatic return to Hekate.
- The RAM result is displayed by the new instance of Nyx on return.

MANUAL INSTALLATION
1. Keep a copy of your current bootloader folder before the trial.
2. Merge the provided bootloader folder with the one at the root of the SD.
   Do not delete your existing folder.
3. Launch hekate_ctcaer_6.5.4_custom.bin with your usual method.
4. For the home screen: Nyx Settings -> Layout -> Tiles / Carousel,
   then Save & reload.
5. For the measurements: Diagnostic tab, then a category or HWTest Summary.
   The Export button saves the report in bootloader/diagnostics/.
6. For RAM: Diagnostic -> Isolated RAM test -> Run the RAM test.
7. For the language: Nyx Settings -> Language -> choose -> Save & reload.
   Closing cancels the choice. The language and the layout are independent.
   Without a language setting, English is used. The paths, user names,
   technical reports and the interface of the RAM service remain as they are.

No nyx.ini nor hekate_ipl.ini is provided: the archive does not replace
your settings and boot entries. The custom colours remain
used; the modernised default theme can be chosen in Color Theme.

RAM TEST AND RETURN
Nyx is exited during the test. Hekate is kept in a small area
already excluded from the first 4 MiB, then reloaded at the end. The menu is forced
on return to avoid the usual autoboot. A cancellation or a failing test
also produces a return result. A corrupted return image
is refused and offers physical restart/power-off commands.
A hardware failure or a memory hang may prevent any return.
The Planned zone field of the result indicates the available zone, not
proof of complete coverage if the test was interrupted.

INTERPRETATION OF THE RESULTS
Some probes depend on the model or on files present. The decrypted
PRODINFO reads require switch/prod.keys of this console and accessible
SE slots; a missing prerequisite remains reported as such.
The sound test must be confirmed by listening. An observation is not
a success. The physical measurements and the appearance remain to be validated on console.

Documentation, corresponding sources, logs and checksums included.
The unchanged ancillary resources come from the official Hekate 6.5.4 /
Nyx 1.9.4 release; the custom executables are built here.
