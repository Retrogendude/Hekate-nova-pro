## Notice historique complète

Les instructions et chemins ci-dessous concernent l’archive de cette version. Ils ne décrivent pas automatiquement la dernière version. Les limitations et validations restent celles indiquées à l’époque.

HEKATE 6.5.4 / NYX 1.9.4 - INTERFACE TRANSPARENTE ET LANGUES, PROTOTYPE 6

Compilation complete reussie. Cette version reste experimentale :
aucun essai sur console reelle n'a encore ete effectue.

NOUVEAUTES
- Theme moderne et arrondi applique aux menus, sous-menus et controles.
- Fonds de cartes, icones, panneaux, boutons et selections transparents.
  Les fenetres superposees et dialogues gardent une base sombre lisible.
- Icone Diagnostic ajoutee dans l'onglet et sur la carte d'accueil.
- Choix de langue : anglais, francais, espagnol, italien, russe, allemand,
  portugais. Polices Unicode pour les accents et le cyrillique.
- Deux accueils : Tuiles et Carrousel, conserves dans les reglages Nyx.
- Toute la table HWTest-RCM 0.15 : 42 entrees natives, categories,
  execution individuelle, resultats detailles et export sur carte SD.
- Test RAM separe : une sequence des 7 motifs avances sur les zones
  accessibles non reservees, puis retour automatique a Hekate.
- Le resultat RAM est affiche par la nouvelle instance de Nyx au retour.

INSTALLATION MANUELLE
1. Conserve une copie de ton dossier bootloader actuel avant l'essai.
2. Fusionne le dossier bootloader fourni avec celui a la racine de la SD.
   Ne supprime pas ton dossier existant.
3. Lance hekate_ctcaer_6.5.4_custom.bin avec ta methode habituelle.
4. Pour l'accueil : Reglages Nyx -> Disposition -> Tuiles / Carrousel,
   puis Enregistrer & recharger.
5. Pour les mesures : onglet Diagnostic, puis une categorie ou Bilan HWTest.
   Le bouton Exporter enregistre le rapport dans bootloader/diagnostics/.
6. Pour la RAM : Diagnostic -> Test RAM isole -> Lancer le test RAM.
7. Pour la langue : Nyx Settings -> Language -> choisir -> Save & reload.
   Fermer annule le choix. La langue et la disposition sont independantes.
   Sans reglage de langue, l'anglais est utilise. Les chemins, noms utilisateur,
   rapports techniques et l'interface du service RAM restent tels quels.

Aucun nyx.ini ni hekate_ipl.ini n'est fourni : l'archive ne remplace pas
tes reglages et entrees de demarrage. Les couleurs personnalisees restent
utilisees ; le theme par defaut modernise peut etre choisi dans Color Theme.

TEST RAM ET RETOUR
Nyx est quitte pendant le test. Hekate est conserve dans une petite zone
deja exclue des premiers 4 Mio, puis recharge a la fin. Le menu est force
au retour pour eviter l'autoboot habituel. Une annulation ou un test en
echec produit aussi un resultat de retour. Une image de retour corrompue
est refusee et propose des commandes physiques de redemarrage/extinction.
Une panne materielle ou un blocage memoire peut empecher tout retour.
Le champ Zone prevue du resultat indique la zone disponible, pas une
preuve de couverture complete si le test a ete interrompu.

INTERPRETATION DES RESULTATS
Certaines sondes dependent du modele ou de fichiers presents. Les lectures
PRODINFO dechiffrees necessitent switch/prod.keys de cette console et des
emplacements SE accessibles ; un prerequis absent reste indique comme tel.
Le test sonore doit etre confirme a l'ecoute. Une observation n'est pas
un succes. Les mesures physiques et l'apparence restent a valider sur console.
