## Full historical notice

The instructions and paths below relate to this version's archive. They do not automatically describe the latest version. The limitations and validations remain those stated at the time.

HEKATE 6.5.4 / NYX 1.9.4 - PERSONALISATION, PROTOTYPE 7

Compiled version, with verification on computer.
No trial on a real console has yet been carried out.
The technical comments are translated offline; their linguistic review
remains useful. The early recovery messages remain in English.

NEW FEATURES
- An Appearance menu groups language, font, size, home screen and animated background.
- SD fonts from /fonts: three ready-to-copy files are provided.
- Nine main sizes, from 20 to 36 pixels, with adapted captions.
- Waves, Particles and Aurora backgrounds, adjustable speed and intensity.
- Cards and scrolling in Tools, Information, Options and Nyx Settings.
- Long titles legible, sized help texts and Diagnostic suited to large texts.
- Seven languages, 3,688 keys and 108 strings of the RAM service in each language.
- The 42 native probes and the RAM test with Hekate return are kept.

INSTALLATION
1. Keep a copy of the current bootloader folder.
2. Merge the provided bootloader and fonts folders with the root of the SD.
   Do not delete the existing folders.
3. Launch hekate_ctcaer_6.5.4_custom.bin with the usual method.
4. Open Nyx Settings -> Appearance (Reglages Nyx -> Apparence in French).
5. Choose language, font, size, layout and effects.
6. Save and reload applies the choices. Close cancels the selection.

The animations are disabled by default and suspend during the probes.
The old settings and the boot entries are not replaced:
no nyx.ini nor hekate_ipl.ini is provided.

PERSONAL FONTS
Convert a TTF/OTF file with outils-polices, then copy the .nyxf file
into fonts at the root of the SD and reload Nyx. Raw TTF/OTF files are not
read directly. Python 3 and Pillow are needed on the computer
only to convert a new font. See documentation/POLICES.md.
A short name, without accents or folder, is required for the .nyxf file.

DIAGNOSTIC
The reports can be exported to bootloader/diagnostics.
The sound test requires a check by listening. The missing prerequisites
and the observations are not presented as successful tests.
Some PRODINFO reads require the keys of this console.

The RAM test exits Nyx, runs the seven advanced patterns and reloads Hekate.
Its texts and glyphs are verified in the area already excluded from the first
4 MiB; the ram-ui-*.bin files are to be kept with the RAM service.
An absent or corrupted pack uses the backup display in English.
A hardware failure or unstable memory may prevent the return.
The planned zone is not proof of coverage if the test is interrupted.

TRANSLATIONS
The menus, commands and source strings of the 42 probes are in the catalogue.
The additions to the technical comments were translated automatically
offline and corrected on the critical terms. Their linguistic quality
has not been fully validated by native speakers.
The component names, registers, paths and personal entries remain
intact. The early recovery messages remain in English.
See documentation/TRADUCTIONS.md for the exact scope.

Sources, licences, checksums and logs of the checks included.
