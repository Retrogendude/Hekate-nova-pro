## Notice historique complète

Les instructions et chemins ci-dessous concernent l’archive de cette version. Ils ne décrivent pas automatiquement la dernière version. Les limitations et validations restent celles indiquées à l’époque.

HEKATE 6.5.4 / NYX 1.9.4 - INTERFACE COMPACTE, VERSION 8

Corrections apres les premiers essais sur console :
- Onglets principaux compacts, sans defilement vertical.
- Contenu entre la navigation du haut et la barre d'etat du bas.
- Reglages Nyx repartis dans Interface et Systeme.
- Apparence repartie dans Langue, Police, Disposition et Effet.
- Boutons ? pour les aides longues et selecteurs visibles.
- Fond uniforme noir/gris, cartes transparentes et contours gris/blancs.
- Angles legerement arrondis. Les pastilles de couleur sont retablies.

FLUIDITE
L'affichage ne presente plus toute l'image pour chaque petite zone modifiee.
Les recherches de caracteres et de textes ont ete accelerees. Les effets
utilisent une petite bande inferieure ; ils se mettent en pause pendant
la navigation, puis reprennent au repos. Ils restent suspendus pendant
les diagnostics. Leur rythme de decoration est distinct de celui des menus.
Les mesures fournies sont des controles sur ordinateur, pas des FPS console.
Cette version 8 doit encore etre validee sur une console reelle.

INSTALLATION
1. Garder une copie du dossier bootloader actuel.
2. Fusionner bootloader et fonts avec la racine de la carte SD.
3. Lancer hekate_ctcaer_6.5.4_custom.bin avec la methode habituelle.
4. Ouvrir Reglages Nyx -> Apparence pour les langues, polices et effets.
Aucun nyx.ini ni hekate_ipl.ini n'est fourni : les reglages sont conserves.
La premiere pastille du menu Couleurs utilise l'accent gris par defaut.
Les anciens fonds d'ecran restent sur la SD ; cette presentation affiche
un fond uni pour faciliter la lecture et reduire le travail de dessin.

UTILISATION
Les fonctions principales sont toutes presentes dans leur onglet.
Les aides ne tiennent plus de place inutilement : le bouton ? les affiche.
Les longs rapports et les listes de fichiers peuvent toujours defiler.
Les deux accueils Tuiles et Carrousel sont conserves.
Enregistrer et recharger applique les choix d'Apparence. Fermer les annule.

POLICES
Trois polices sont fournies dans /fonts, avec neuf tailles de 20 a 36 pixels.
Pour ajouter une police TTF/OTF, utiliser le convertisseur outils-polices,
puis copier le fichier .nyxf dans fonts a la racine de la SD. Recharger Nyx.
Python 3 et Pillow sont necessaires sur l'ordinateur seulement pour convertir
une nouvelle police. Aucun logiciel supplementaire n'est requis pour utiliser
les polices deja fournies. Voir documentation/POLICES.md.

DIAGNOSTIC ET LANGUES
Les 42 sondes natives et le service RAM separe sont conserves.
Le test RAM recharge Hekate a la fin ; une panne de memoire peut empecher
le retour. Garder les fichiers ram-ui-*.bin avec bootloader/sys/hwtest_ram.bin.
Sept langues sont disponibles. Les commentaires techniques complementaires
ont ete traduits hors ligne et corriges sur les termes critiques ; une
relecture linguistique reste utile. Les messages precoces de secours restent
en anglais. Voir documentation/TRADUCTIONS.md.
