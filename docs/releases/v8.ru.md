# v8 — Компактный интерфейс и плавность
**Languages:** [Français](v8.md) · [English](v8.en.md) · [Español](v8.es.md) · **Русский**

- Удаление крупных вертикальных списков в пользу компактных вкладок и видимых селекторов.
- Содержимое между верхней навигацией и нижней строкой состояния; настройки Interface / System и «Внешний вид» разделены.
- Тёмные прозрачные карточки, менее скруглённые контуры и длинные подсказки, доступные по кнопкам.

**Тип поставки:** скомпилированная предварительная версия, исходный код и исходные файлы сохранены.

## Полное историческое уведомление

Приведённые ниже инструкции и пути относятся к архиву этой версии. Они не описывают автоматически последнюю версию. Ограничения и проверки остаются теми, что были указаны в то время.

HEKATE 6.5.4 / NYX 1.9.4 — КОМПАКТНЫЙ ИНТЕРФЕЙС, ВЕРСИЯ 8

Исправления после первых испытаний на консоли:
- Компактные основные вкладки, без вертикальной прокрутки.
- Содержимое между верхней навигацией и нижней строкой состояния.
- Настройки Nyx распределены по Interface и System.
- «Внешний вид» разделён на «Язык», «Шрифт», «Компоновку» и «Эффект».
- Кнопки ? для длинных подсказок и видимые селекторы.
- Однородный чёрно-серый фон, прозрачные карточки и серо-белые контуры.
- Слегка скруглённые углы. Цветовые маркеры восстановлены.

ПЛАВНОСТЬ
Экран больше не отображает всё изображение для каждой небольшой изменённой области.
Ускорены поиски символов и текстов. Эффекты
используют небольшую нижнюю полосу; они приостанавливаются во время
навигации, затем возобновляются в покое. Они остаются приостановленными во время
диагностики. Их ритм декорации отличен от ритма меню.
Предоставленные измерения — это проверки на компьютере, а не FPS на консоли.
Эту версию 8 ещё предстоит проверить на реальной консоли.

УСТАНОВКА
1. Сохранить копию текущей папки bootloader.
2. Объединить bootloader и fonts с корнем SD-карты.
3. Запустить hekate_ctcaer_6.5.4_custom.bin обычным способом.
4. Открыть Reglages Nyx -> Apparence для языков, шрифтов и эффектов.
nyx.ini и hekate_ipl.ini не предоставляются: настройки сохраняются.
Первая ячейка меню «Цвета» использует серый акцент по умолчанию.
Старые обои остаются на SD; это оформление отображает
однородный фон для облегчения чтения и снижения объёма отрисовки.

ИСПОЛЬЗОВАНИЕ
Все основные функции присутствуют на своей вкладке.
Подсказки больше не занимают лишнего места: кнопка ? показывает их.
Длинные отчёты и списки файлов по-прежнему можно прокручивать.
Оба главных экрана — Плитки и Карусель — сохранены.
«Сохранить и перезагрузить» применяет выбор «Внешнего вида». «Закрыть» отменяет его.

ШРИФТЫ
В /fonts предоставляются три шрифта с девятью размерами от 20 до 36 пикселей.
Чтобы добавить шрифт TTF/OTF, используйте конвертер outils-polices,
затем скопируйте файл .nyxf в fonts в корне SD. Перезагрузите Nyx.
Python 3 и Pillow нужны на компьютере только для преобразования
нового шрифта. Для использования уже предоставленных шрифтов
дополнительное программное обеспечение не требуется. См. documentation/POLICES.md.

ДИАГНОСТИКА И ЯЗЫКИ
42 встроенных зонда и отдельная служба RAM сохранены.
Тест RAM перезагружает Hekate в конце; сбой памяти может воспрепятствовать
возврату. Храните файлы ram-ui-*.bin вместе с bootloader/sys/hwtest_ram.bin.
Доступны семь языков. Дополнительные технические комментарии
были переведены офлайн и исправлены по критичным терминам; языковая
проверка остаётся полезной. Ранние сообщения восстановления остаются
на английском. См. documentation/TRADUCTIONS.md.

Исходный код, лицензии, проверки и предварительные изображения реального графического движка включены.
