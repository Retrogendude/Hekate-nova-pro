## Full historical notice

The instructions and paths below relate to this version's archive. They do not automatically describe the latest version. The limitations and validations remain those stated at the time.

HEKATE 6.5.4 / NYX 1.9.4 - STUDIO, VERSION 9

PRESENTATION
The Studio style is integrated into the program: side navigation,
anthracite background, purple accents, 6-pixel corners and icon frames.
A 28-pixel halo indicates the selected icon. It is fixed and does not
trigger any continuous refresh. The main settings use
switches with position and translated ON/OFF text.

The main pages remain between the header and the status bar, without
vertical scrolling. Tools, Information and Diagnostic have icons.
The home screen keeps Tiles and Carousel. The titles adapt to the available
space; the long help texts remain accessible via the ? buttons.
The detailed windows keep their close bar and the same theme.

INSTALLATION
1. Keep a copy of the current bootloader folder.
2. Merge bootloader and fonts with the root of the SD card.
3. Launch hekate_ctcaer_6.5.4_custom.bin with the usual method.
4. Open Nyx Settings -> Appearance for languages, fonts and layout.
No nyx.ini nor hekate_ipl.ini is provided: the settings are kept.
The new style is displayed when this Nyx loads. The first dot of the
Colors menu corresponds to the default purple accent; the other accent and
background choices already saved remain available.

SMOOTHNESS
The optimisations of version 8 are kept: one presentation per
frame, accelerated text/glyph searches and effects limited to a bottom
strip. The effects suspend during navigation and the tests.
The halo is drawn only when the selection changes or the icon is displayed.
The checks on computer do not measure the real FPS of the console.
This version 9 still has to be tried on a real console.

FONTS AND LANGUAGES
Three fonts are provided in /fonts, with nine sizes from 20 to 36 pixels.
To add a TTF/OTF font, use outils-polices, copy the
.nyxf file into fonts at the root of the SD, then reload Nyx. Python 3 and Pillow
are needed only on the computer for this conversion.
Seven languages remain available. Save and reload applies the
Appearance choices; Close cancels them. See documentation/POLICES.md and
documentation/TRADUCTIONS.md for the details and limits of the translations.

DIAGNOSTIC
The 42 native probes and the separate RAM service are kept.
The RAM test reloads Hekate at the end. Keep the ram-ui-*.bin files
with bootloader/sys/hwtest_ram.bin. The reports and the file lists
can still scroll.

Sources, licences, verification results and previews of the real graphics engine
included. The battery/time values of the previews are demonstrative.
