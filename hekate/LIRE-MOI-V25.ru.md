# Hekate Nova Pro25 — проверка переподключения Joy-Con
**Languages:** [Français](LIRE-MOI-V25.md) · [English](LIRE-MOI-V25.en.md) · [Español](LIRE-MOI-V25.es.md) · **Русский**

Сохранённая база: Hekate 6.5.5 / Nyx 1.9.5. Интерфейс и настройки Nova сохранены.

Отчёт v24 подтверждает успешную аутентификацию для одного подключения, затем
потерю связи во время включения шифрования (08). Исправление
формата ключей из v24 сохранено. Остаётся проблема подключения.

Эта версия требует, чтобы консоль выполняла главную роль, когда Joy-Con
инициирует переподключение, и запускает исходящие попытки последовательно.
Эти изменения проверены на ПК. Их эффективность на консоли остаётся
подлежащей подтверждению: отчёт сам по себе не позволяет уверенно отнести
обрыв к Bluetooth-роли.

## Установка и проверка

1. Скопируйте содержимое ZIP в корень SD-карты, заменив файлы
   папки **bootloader**. Файлы настроек не поставляются.
2. При необходимости используйте **hekate_nova_pro_6.5.5_v25.bin**, затем полностью
   перезагрузите консоль.
3. Откройте **Настройки → TV / Dock → Беспроводные Joy-Con**. Прикрепите Joy-Con,
   выберите **Прочитать сопряжения**, затем отсоедините их и включите Bluetooth.
4. Нажмите кнопку, чтобы разбудить их, и проверьте кнопки/стики.
5. Выберите **Остановить Bluetooth** после проверки. Отчёт находится в
   `bootloader/bluetooth/last-session.txt`.

Не используйте только состояние светодиодов как критерий: счётчики
отчётов и работа команд являются полезными индикаторами.
Ключи остаются в памяти, и их нужно перечитывать после каждой перезагрузки.

## Новый отчёт

- AUTH=00 SEEN=1: событие подтверждает успешную аутентификацию.
- ENC=00 SEEN=1 ENABLED=1 или 2: шифрование включено, пока связь активна.
- ENC=08 SEEN=1: связь истекла на этом этапе.
- DISC: причина отключения сохранена.
- ROLE=00: главная роль, известная стеку; 01: вторичная; FF: неизвестна.
  Полученные изменения роли появляются в трассе13; политика,
  запрошенная при принятии, появляется в трассе14.
- HOST=1: идентичность контроллера соответствует идентичности импортированных сопряжений.
- SEEN=0: соответствующее событие не наблюдалось; 00 само по себе не доказывает успех.

Последние результаты остаются доступными после «Остановить», даже если нажать
второй раз. Следующий запуск Bluetooth открывает новый сеанс.
Отчёт включает версию контроллера, без адресов, ключей и необработанных пакетов.

Безопасность связи сохранена. Никакое новое сопряжение и никакая запись
ключей не выполняются. Предыдущие исправления Nyx, дока и диагностики
сохранены. Собственная лицензия BTstack включена в документацию.
